# UI/UX Pro Max: Design Intelligence Constitution

Based on `nextlevelbuilder/ui-ux-pro-max-skill`. This skill governs visual aesthetics, layout density, and interaction quality.

## Anti-AI-Slop Constitution
1. **No Floating Pastel Blobs:** Avoid generic washed-out purple/cyan rounded cards with huge drop shadows.
2. **Dense, Purposeful Information:** Financial dashboards require high-density, scannable data layouts, not giant empty whitespace cards.
3. **Typography Discipline:**
   - Use tabular, mono-spaced numerals (`font-mono` / `tabular-nums`) for currency values, stock prices, percentages, and timestamps.
   - Distinct weights: Bold headings (600/700), medium labels (500), regular body (400).
4. **Color Science & WCAG AA Contrast:**
   - Financial conventions: Green (`#16a34a` / `#15803d`) for positive changes, Red (`#dc2626` / `#b91c1c`) for negative changes.
   - Text on background must exceed a 4.5:1 contrast ratio.
   - Dark sidebar: Deep slate (`#0f172a` / `#020617`), subtle borders (`#1e293b`), crisp bright white accents.
5. **Interactive & Responsive Standards:**
   - Data tables: Hover highlight on rows, sticky table headers, right-aligned monetary values.
   - Charts: Custom styled tooltips showing crosshairs, currency formatting, and legible legends.
   - Micro-interactions: Active state ring indicators, smooth transitions on interactive cards (`transition-transform`, `duration-150`).
